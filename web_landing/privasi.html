Kebijakan Privasi KasirKita

Berlaku sejak 25 November 2026 · Pengembang: ASDEV.id

KasirKita adalah aplikasi kasir yang bekerja di HP Anda tanpa akun online. Halaman ini menjelaskan data apa yang dipakai aplikasi dan ke mana data itu pergi.

1. Data yang disimpan

Akun pengguna (nama pengguna dan password yang di-hash), profil toko, produk, foto produk, transaksi, pengeluaran, shift, dan log aktivitas. Semua data ini hanya tersimpan di penyimpanan HP Anda. Kami tidak punya server untuk data ini dan tidak dapat melihatnya.

2. Data yang dikirim ke internet

  • Cek versi: saat dibuka, aplikasi mengunduh file versi dari server kami untuk mengetahui apakah ada pembaruan. Tidak ada data Anda yang dikirim.
  • Halaman Dukung Developer: menampilkan halaman web kami. Tautan ke Instagram atau TikTok dibuka di aplikasi atau browser terkait, yang memiliki kebijakan privasinya sendiri.
  • Pembaruan aplikasi: lewat Google Play, sesuai kebijakan Google.

Kami tidak memakai iklan, analitik, atau pelacak pihak ketiga di dalam aplikasi.

3. Izin yang dipakai

  • Bluetooth: untuk mencari dan terhubung ke printer struk thermal.
  • Foto/galeri: hanya saat Anda memilih foto produk atau logo toko.
  • File: hanya saat Anda membuat atau memulihkan backup, atau mengekspor laporan.
  • Internet: untuk cek versi dan halaman Dukung Developer.

4. Backup dan berbagi

File backup dan ekspor laporan dibuat di HP Anda. Jika Anda membagikannya (misalnya lewat WhatsApp atau Google Drive), file itu mengikuti kebijakan layanan yang Anda pilih. Simpan file backup di tempat yang aman karena berisi data toko Anda.

5. Menghapus data

Hapus aplikasi atau hapus data aplikasi dari pengaturan HP untuk menghapus semua data KasirKita. File backup yang Anda simpan di tempat lain perlu dihapus sendiri.

6. Anak-anak

KasirKita ditujukan untuk pelaku usaha dan tidak ditujukan untuk anak di bawah 13 tahun.

7. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal di atas akan diperbarui dan versi terbaru selalu ada di halaman ini.
