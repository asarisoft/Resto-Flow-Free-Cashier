# UI Polish (font, ikon slim, kontras, komponen) Implementation Plan

> **For agentic workers:** Kerjakan task per task. Centang checkbox (`- [ ]` → `- [x]`) tiap step selesai. Berhenti & tanya 1 pertanyaan kalau ambigu — jangan menebak. **Plan ini belum disetujui user: jangan dikerjakan sebelum user bilang "ok".**

**Goal:** Tampilan lebih rapi dan terbaca: font baru (offline), semua ikon diganti set ikon slim, kontras lolos 4.5:1, kontrol sentuh ≥ 48dp, bahasa UI konsisten Indonesia.

**Architecture:** Semua gaya lewat token (`AppColors`, `AppTypography`, `AppIcons`) — layar tidak boleh hardcode warna/ikon/font. Komponen yang dipakai >1 tempat jadi widget bersama (aturan AGENTS.md).

**Tech Stack:** Flutter, Material 3, font di-bundle di `assets/fonts/` (app 100% offline), paket ikon slim.

**Spec:** `docs/DESIGN.md`, hasil audit `ui-ux-pro-max` (sesi 2026-11-15), `AGENTS.md`.

## Global Constraints
- Baca dulu: `AGENTS.md`, `docs/DESIGN.md`. Pakai skill `ui-ux-pro-max` + `frontend-design`; sebelum bilang selesai cek `web-design-guidelines`.
- Perubahan sekecil mungkin (`ponytail`). Jangan tambah fitur baru (mis. tombol uang cepat, dark mode, grafik → lihat "Di luar plan").
- App offline: DILARANG memuat font/ikon dari internet saat runtime.
- Tidak ada `Icons.*`, `Colors.*` mentah, `GoogleFonts.*`, atau hex di luar `lib/core/theme/` setelah plan selesai.
- Teks UI Bahasa Indonesia; target sentuh ≥ 48×48dp; kontras teks ≥ 4.5:1, batas kontrol input ≥ 3:1.
- Uang tetap `int`. Jangan ubah logika bisnis.
- 1 task = 1 commit (`feat:`/`fix:`/`refactor:`/`docs:`). Jangan push.
- Jalankan Flutter lewat `fvm flutter ...`.

## Review Focus
- Ukuran teks sistem terbesar: layar POS & dialog bayar tidak overflow.
- Layar 375dp lebar dan landscape: tidak ada scroll horizontal.
- Produk habis (`ready=false`): jelas tidak bisa di-tap, bukan sekadar tidak bereaksi.
- Angka uang rata kolom (tabular) di font baru.
- Pembaca layar: kontrol tanpa teks punya label.
