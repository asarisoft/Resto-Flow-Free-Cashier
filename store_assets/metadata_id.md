Kasir Ceria adalah aplikasi kasir (POS) offline dan gratis untuk warung, cafe, resto, dan usaha kecil lain. Semua jalan offline di HP Anda. Tanpa internet, tanpa langganan, tanpa akun online.

Catat penjualan, cetak struk, pantau stok, dan lihat laporan omzet dari satu aplikasi yang ringan.

FITUR UTAMA

Kasir cepat
- Cari menu lewat kolom pencarian atau saring per kategori produk.
- Tambah pesanan, ubah jumlah, lalu bayar dalam beberapa ketukan.
- Cocok untuk jam ramai di warung makan, cafe, kedai kopi, dan resto kecil.

Struk Bluetooth
- Cetak struk ke printer thermal Bluetooth ukuran 58mm atau 80mm.
- Struk rapi dengan identitas usaha Anda.
- Hubungkan printer sekali, lalu cetak setiap transaksi.

Laporan penjualan
- Lihat omzet dan laba usaha Anda dalam satu layar.
- Riwayat transaksi tersimpan rapi di HP.
- Catat pengeluaran usaha supaya laba bersih terlihat jelas.

Stok dan produk
- Kelola daftar produk, harga, dan kategori sendiri.
- Pantau stok barang agar tidak kehabisan saat dibutuhkan.

Multi pengguna
- Peran Owner dan Kasir dengan hak akses berbeda.
- Owner mengatur produk, printer, pengguna, dan laporan. Kasir fokus melayani pelanggan.
- Fitur shift untuk mencatat kas awal dan kas akhir tiap giliran kerja.

Data milik Anda
- Semua data tersimpan di HP, bukan di server kami.
- Backup manual ke file, lalu pulihkan di HP baru saat Anda pindah perangkat.
- Aplikasi tidak memakai sinkronisasi cloud.

Mendukung HP dan tablet
- Tampilan menyesuaikan layar HP maupun tablet, cocok sebagai kasir di meja.

KENAPA KASIR CERIA
- Gratis dipakai, tanpa biaya bulanan.
- Kasir offline: tetap bisa berjualan saat sinyal hilang.
- Ringan dan mudah dipelajari, bahkan untuk karyawan baru.
- Dibuat untuk kebutuhan UMKM Indonesia.

COCOK UNTUK
Warung makan, kedai kopi, cafe, resto kecil, toko kelontong, kios, katering rumahan, dan usaha UMKM lain yang butuh aplikasi kasir sederhana.

CATATAN
Aplikasi hanya memeriksa file versi untuk info pembaruan saat ada koneksi. Tidak ada data usaha atau pelanggan yang dikirim keluar dari HP Anda.

## 4. Kategori, tag, rating
- Kategori: Bisnis (Business). Alternatif: Produktivitas.
- Tag (pilih sesuai daftar Play Console): Bisnis, Keuangan/Akuntansi, Manajemen Inventaris atau Point of Sale bila tersedia.
- Content rating (IARC): tanpa kekerasan, konten dewasa, judi, atau interaksi pengguna. Perkiraan: Semua umur (3+). Isi kuesioner jujur; aplikasi bukan untuk anak, jadi target audiens 18+.
- Harga: Gratis. Tanpa iklan dan tanpa pembelian dalam aplikasi (konfirmasi sebelum diisi di Console).

## 5. Data safety (ringkas)
- Data dikumpulkan: tidak ada. Data dibagikan: tidak ada.
- Data usaha (produk, transaksi, pengguna) disimpan lokal di HP, tidak dikirim ke server.
- Satu-satunya akses jaringan: mengambil file version.json untuk cek versi terbaru (tanpa data pribadi).
- Enkripsi saat transit: tidak berlaku bila tidak ada data terkirim (pastikan URL version.json memakai HTTPS).
- Hapus data: pengguna menghapus data lewat hapus aplikasi atau data aplikasi di HP.
- Izin: INTERNET (cek versi), Bluetooth (printer). Cocokkan dengan AndroidManifest sebelum submit.
